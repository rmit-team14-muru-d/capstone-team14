## Risks / Issues Raised

**Single-reviewer sign-off** — The requirements document was reviewed and approved by the PM alone. With the BA authoring and the PM approving, there is no independent check before the document reaches development.

**Documentation not yet in version control** — The requirements document exists outside Git until Action 3 completes. The assignment requires all non-Planner documentation to be stored in the repository.

**Role concentration in UX/BA** — Following the loss of a developer, Ziggy holds both UX and BA responsibilities. Design decisions are queued behind requirements work, which may delay developers.

**Developers not yet unblocked** — Implementation cannot begin until repository access and the shared Firebase configuration are in place.
